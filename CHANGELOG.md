# Changelog

## 0.1.0 — 2026-10-29

- Initial release of OpenCode RTL for VS Code and Antigravity.
- Arabic-first RTL chat UI with automatic English fallback and direction override.
- Local OpenCode server management with free-port selection, external server support, and Basic auth.
- Live streaming for text, reasoning, tools, permissions, questions, todos, and session status.
- Session sidebar and editor panel with shared state.
- Session search, fork, delete, Markdown export, model and agent pickers.
- File diff viewer, editor selection actions, slash commands, and configurable send key.
- Light and dark themes, docked sidebar layout, and responsive panel layout.
